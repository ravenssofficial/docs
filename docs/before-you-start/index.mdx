# Before you start

Before you dive into configuring your client, there are a few essential things you need to understand. 

:::warning[IMPORTANT]
**We do NOT develop or own any clients.**  
We only provide optimized configurations, module breakdowns, and detection statuses for popular mainstream clients.
:::

---

### 1. Missing Modules?
If you are looking for a specific module in our docs and can't find it, there is a very good reason for that. 
* **It's probably blatant.** If a module is highly detectable on modern anticheats and obvious, we purposely leave it out because this is a closet cheating guide.
* **It's already detected.** We constantly update our docs. If a module becomes unsafe to use, it gets removed.
* **It's irrelevant.** Although we try to include as many modules and clients as possible, we cannot include every single module on every single client.

### 2. Staff Bans & False Bans
No config is 100% bypassable if you behave like a robot.
* **Staff can always ban you.** Even if your settings are technically undetectable, it can be obvious that you are cheating, like double sneaking while diagonally bridging or spinning around with aimassist.
* **Be prepared for false bans.** Anticheats are not perfect. Sometimes lag, weird ping spikes, experimental checks and server-side glitches can trigger a false positive. Use alternate accounts if you want to be completely safe.

### 3. Play Smart
Configs are just a tool to help you stay undetected, but your playstyle is what actually keeps you safe. Keep your settings realistic, don't push your luck with blatant settings and toggling, and always read the specific notes for each client.
