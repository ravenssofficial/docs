# Tutorial

To load configs on Drip Lite, you need to click on a config link.  
A preview of the config will open. Click here to import it to your configs.
![](/img/config5.png)  
After importing it, go to your web config and press this button to open your config list, where the imported config will be located.  
![](/img/config6.png)
