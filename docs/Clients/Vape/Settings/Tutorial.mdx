# Tutorial

To load public configs on Vape V4, you need to go to the profiles tab and click here.  
![](/img/config2.png)  
After that, just input the config name or config code in the search bar andclick on the config you want.
![](/img/config3.png)  
Press "Download" to import the config to your profiles.
![](/img/config4.png)
