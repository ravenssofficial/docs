## Overview

In vanilla Minecraft, hitting an enemy causes your character to stop sprinting for a brief moment, which slows down your momentum.  
KeepSprint completely removes this slowdown, keeping your movement speed at its maximum during combat.  

While this is useful for maintaining speed during combos, it is highly detectable. Modern prediction-based anticheats, e.g. Polar and Watchdog, can easily detect the lack of speed reduction during hits and will flag this module quickly.

---

:::info[Vape V4]

If you are using Vape V4, you can get a NoStop SprintReset by enabling the reset sprint option.  
You can read more about how this works on [this](/docs/Modules/Movement/SprintReset) page.

Keeping this option enabled with the multiplier set to 0.6x is safe on almost every anticheat.

:::
