# Autoclicker
This module's detectability heavily depends on the **server** you're playing on.

A difference of 4 CPS between the minimum and maximum CPS should let you remain undetected on every server.

If the client you're using has a **fixated CPS**, make sure to turn every type of **randomization** on and use less than 15 CPS

:::tip

Some clients have a **butterfly** or **simulate double clicks** mode. On strict anticheats, you should turn it on if you want an average CPS of 16 or higher.
If the client you're using does not have such modes, refrain from going over 15 CPS.

:::
