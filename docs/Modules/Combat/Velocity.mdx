# Velocity
This module has **multiple modes** on most clients:

## Vanilla/Normal
:::danger

This mode is **highly detectable** on anticheats at any value.

:::

## Lag

Uses **lag** to make you take less knockback, especially during combos.

As any other **lag-based** mode, it's risky on stricter anticheats.

:::info

On certain clients, this will be a **standalone module** called **KnockbackDelay**

:::

## JumpReset

Jumps when you get hit to reduce knockback.

As long as you use a chance between 20-35% you should be fine. If possible, lowering the accuracy would work very well too.

:::info

On certain clients, this will be a **standalone module.**

:::
