# Knockback Displacement
This module reproduces **human behaviour**, but with bad settings it can get you **staff banned.**

Make sure to use a **higher delay** to look more legit.

:::tip

If you don't want the enemies to see you flicking, you can turn on the blink/hide rotation from players option.

:::
