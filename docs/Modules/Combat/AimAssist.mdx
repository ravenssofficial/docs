# AimAssist
This module is **undetectable** as long as you use reasonable settings.

On some clients, AimAssist uses your sensitivity to calculate the aim speed, so adjust the settings according to your preferences.

Some strict anticheats can ban you if you're aiming directly at the enemy's closest point or center too often and too perfectly.

To avoid this, you should use minimum angle with a value around 10-15 degrees.

:::note

AimAssist is supposed to **help** you aim, not aim for you. Using it as an aimbot on strict anticheats might get you **banned.**

:::
