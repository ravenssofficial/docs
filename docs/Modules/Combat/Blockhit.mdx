# Blockhit
This module usually has **multiple modes** on most clients:

### Automatic/Prediction
This mode will blockhit after hitting someone or predict when you're gonna hit and block accordingly. It's completely undetectable.

### Manual

This mode will spam your block button while you're holding it. It's also completely undetectable.

:::warning

Lag modes and options are detectable and patched on modern anticheats.

:::
