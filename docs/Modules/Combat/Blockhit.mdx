## Overview

Blockhit automates sword-blocking inputs during active combat. By timing your defensive blocks, the module helps you take less damage and execute sprint-reset combos effortlessly. Because the standard modes send valid, vanilla-compliant interaction packets, the module is completely undetectable.

---

## Mechanics

* **Automatic:** Automatically triggers a block immediately after you register a successful hit
* **Prediction:** Dynamically times blocks based on incoming enemy attacks.
* **Manual:** Automates rapid blocking only while you actively hold down your block key.

---

:::warning[Bypass Compatibility]

Avoid using **lag-based modes** built into some blockhit modules. Modern anticheats like Polar have mostly patched these methods.

:::
