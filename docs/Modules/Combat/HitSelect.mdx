---

## Overview

HitSelect controls the timing of your attacks instead of letting every click register instantly. By delaying hits until the target can get hit again, it ensures you keep as much momentum as possible.

HitSelect is 100% safe from anticheats. Because it only filters your actual clicks, the server receives completely normal packets that look like perfect human timing.

---

:::tip[Input Compatibility]

HitSelect works with any input method. You can click manually or use an external Autoclicker; the module will filter the clicks properly in the background.

:::
