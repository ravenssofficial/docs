# Killaura

:::danger

You must have proper movement fixation to use this module. Otherwise, you will be banned almost instantly.

:::

This module is **highly susceptible** to **flags** and **bans**, depending on the client you're using and the settings.

You should generally not go above **120 degrees** for the aiming angle and make sure the aim speed isn't too fast


:::note

If you're using Vape V4, make sure you're not using the real killaura, but silentaura. Killaura is an old, deprecated module which will get you banned.

:::
