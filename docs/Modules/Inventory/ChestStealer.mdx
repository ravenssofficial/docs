## Overview

In fast-paced gamemodes like SkyWars or BedWars, looting chests quickly is game-changing. ChestStealer automates this process by instantly moving items from any opened chest directly into your inventory, saving you precious seconds at the start of a match.

While the module is fundamentally safe to use, you should always use realistic delays and a shuffle option if the client you're using supports it.

---

:::tip[GUIs]

Always enable a **Check In Menu** option to prevent the module from attempting to take items from GUIs

:::
