## Overview

InventoryManager automates this entire process by automatically throwing away useless items (like excess blcoks or weaker gear) and rearranging your essential tools and weapons into their designated hotbar slots.

While organizing is completely safe, doing it at superhuman speeds will instantly trigger alerts on any competent anticheat. Always configure the module to use realistic delays that mimic human clicks.

---

:::danger

Never enable options that allow you to use this module while moving. Modifying or organizing inventory slots while sending movement packets to the server will make most anticheats flag you for illegal inventory movement.

:::
