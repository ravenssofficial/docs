### Overview

BlockIn is a utility module that automatically blocks you inside a shell of blocks. It is most commonly used in minigames like BedWars to protect yourself from getting knocked away while breaking a bed, or to quickly box yourself in when you are low on health.

This module is generally undetectable and not blatant, as long as you don't go overboard with the speed.

---

:::tip[BedWars]

If you're playing BedWars, use the **BedFinder** option, which helps you block in inside beds

:::
