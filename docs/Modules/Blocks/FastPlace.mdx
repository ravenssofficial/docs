### Overview

In vanilla Minecraft, there is a built-in delay between block placements when you hold down the right mouse button.   
Fast Place bypasses this restriction, allowing you to place blocks continuously and at a much faster rate.

This module is safe to use on most servers, but you should avoid using it on exceptionally advanced anticheats.

---

:::tip

On exceptionally advanced and strict anticheats, using [RightClicker](/docs/Modules/Blocks/RightClicker) will let you stay undetected, while fastplace could flag in some cases.

:::
