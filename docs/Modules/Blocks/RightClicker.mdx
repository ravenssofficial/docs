### Overview

RightClicker automates your right-clicks by generating clicks at a specified speed (CPS) when you hold down the key.  
Anticheats are generally much more lenient towards this module than FastPlace, as it mimics real mouse clicks rather than completely removing the game engine's placement delay.

---

:::tip[For More Consistency]

If you want perfectly consistent block placements without relying on clicking speeds, and you are playing on a server with standard anticheat, try using [FastPlace](/realravenss-docs/Modules/Blocks/FastPlace) instead.

:::
