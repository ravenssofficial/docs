## Overview

Nametags replaces the default player names with clearer, customizable text plates that can render through walls. It allows you to see essential details about other players, such as their health, distance, and equipped gear, without having to get close to them.

Because this module only formats and displays information that your client already receives from the server, it is 100% safe and undetectable.

---

:::tip[Spot Enchantments Early]

Although many competitive servers spoof or hide player enchantments to prevent cheating, keeping the option to show enchantments active is still highly useful in gamemodes like BedWars to instantly check if an opponent has sharpness on their sword.

:::
