## Overview

Chams allows you to see the entire 3D model of a player through walls. Unlike basic box ESP, this displays the actual character model in real time, making it incredibly easy to see their exact posture, and which way they are looking behind cover.

Since this module only changes how your client renders player models that are already loaded in your game memory, it is 100% safe and undetectable.

---

:::tip[Track Movements Behind Cover]

This is extremely useful in close-quarters fights because you can see the exact moment an opponent stops crouching, allowing you to react before they even peek.

:::
