## Overview

BedPlates displays the exact blocks protecting a bed. It lets you see the defense setup from a distance, showing you which beds are the easiest to target.

Since this module only visualizes block data already loaded by your client, it is 100% safe and undetectable.

---

:::tip[Target the Weakest Bases]

You can use this to quickly find which teams have weak bed defenses, like just wool, and target them first.

:::
