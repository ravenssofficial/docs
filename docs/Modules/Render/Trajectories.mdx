## Overview

Trajectories calculates and renders a visual line showing the exact flight path of a projectile before you even fire it.  
It also shows the path of enemy projectiles once they have been thrown or shot, letting you see exactly where they will land.

Since this module only performs local physics calculations based on your current aiming angle or loaded entity movement, it is 100% safe and undetectable.

---

:::info[Alternative Names]

While this features both your own and enemy flight paths in one place, some clients split these features up.  
The function that tracks enemy projectiles mid-air is often found as a standalone module called **Projectiles.**

:::
