## Overview

Fullbright forces the game's brightness level to its maximum value, completely removing shadows and darkness. It allows you to see clearly in caves, ravines, and night maps without needing to place torches or use Night Vision potions.

Since this feature only changes how light is rendered on your screen, it is 100% safe and undetectable.

---

:::info[Standard Client Feature]

This is a standard utility found in almost every legitimate PvP client. It is completely allowed on all major servers since it provides no server-side advantages, only a visual convenience.

:::
