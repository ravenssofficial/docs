## Overview

In game modes like BedWars, fireballs are frequently used to knock players off bridges or destroy defenses. AntiFireball automates the process of deflecting these projectiles.  
The moment an incoming fireball enters your range, the module will instantly attempt to intercept it.

Since this module only replicates legitimate player behavior, simply automating the physical aim and left-click input within realistic limits, it is completely safe to use and will not trigger anticheat flags.

---

:::note[Higher Latencies]

If you play on a higher latency, such as 200ms, this module might not always work.

:::
